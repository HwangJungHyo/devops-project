# Runbook

운영 중 실제로 손을 움직여야 할 때 보는 문서. 개념 설명이 아니라 **절차**를 적는다.

## 작성 원칙

- 명령어를 그대로 복사해 실행할 수 있게 쓴다
- "적절히 조정한다" 같은 표현을 쓰지 않는다. 판단이 필요하면 판단 기준을 적는다
- 각 문서 첫 줄에 **이 문서를 언제 여는지**를 쓴다
- 새벽 3시에 잠에서 깬 사람이 읽는다고 가정한다

## 누적 규칙

Phase가 끝날 때마다 해당 Phase에서 만든 것의 운영 절차를 여기에 추가한다. 마지막에 몰아서 쓰지 않는다.

|---|---|---|
| 1 | `local-development.md` — 로컬 환경 실행 | 예정 |
| 2 | `infrastructure.md` — Terraform 적용 절차 | 예정 |
| 3 | `deployment.md` — 배포 절차 | 예정 |
| 5 | `secrets.md` — 시크릿 추가·교체 절차 | 예정 |
| 6 | `rollback.md` — 롤백 절차 | 예정 |
| 7 | `alerts.md` — 알람별 대응 절차 | 예정 |
| 8 | `troubleshooting.md` — 로그·메트릭 조회 방법 | 예정 |

## 검증

Runbook은 **읽어서 되는지**가 아니라 **따라 해서 되는지**로 검증한다. 작성자가 아닌 사람이 문서만 보고 수행에 성공해야 통과다.
