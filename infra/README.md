# Infrastructure

이 디렉토리는 AWS 인프라를 코드로 정의한다. Phase 2부터 채워진다.

## 현재 상태

아직 비어 있음. ADR-0001(배포 플랫폼 선정)이 확정되어야 구조가 정해진다.

## 예정 구조 (ADR-0001 확정 후 조정)

```
infra/
├── modules/          # 재사용 가능한 구성 단위 (network, ecr, rds, ...)
└── envs/
    └── prod/         # 환경별 실제 구성
```

## 착수 전 결정해야 할 것

- [ ] IaC 도구 선정 (Terraform / OpenTofu / CDK) → ADR 필요
- [ ] 상태 파일(state) 저장 위치와 잠금(lock) 방식 — **로컬에 두지 않는다**
- [ ] 환경 분리 방식 (workspace vs 디렉토리 분리)
- [ ] 네이밍 컨벤션과 필수 태그 (`Project`, `Environment`, `ManagedBy`)
- [ ] CI에서 인프라를 적용할 때 쓸 IAM 역할과 신뢰 정책

## 원칙

- **콘솔에서 만든 리소스는 없다.** 손으로 만든 것이 하나라도 있으면 재현이 불가능해진다. 불가피하게 수동 생성한 것이 있다면 이 문서에 목록으로 남긴다
- `terraform plan`이 아무 변경도 출력하지 않는 상태가 정상이다. drift가 보이면 원인을 찾는다
- 상태 파일에는 시크릿이 평문으로 들어갈 수 있다. 저장소 접근 권한을 인프라 담당자로 제한한다
